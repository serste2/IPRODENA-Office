# Inula delle Grotte Site

Static launch site for i prodotti della Natura / Inula delle Grotte.

## Local Preview

Open `index.html` directly in a browser, or serve the folder with any static server.

## Vercel

This project does not require a build step.

- Framework preset: Other
- Root directory: `inula-launch-site`
- Build command: leave empty
- Output directory: `.`

## Notes

- `assets/frecoro.gif` is the Frecoro character reference.
- Product package visuals are currently CSS-built placeholders so they can be replaced by final scans, drawings, or generated packshots.
